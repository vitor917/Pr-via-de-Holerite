# Previa-de-Holerite
Este arquivo é uma aplicação web (HTML/CSS/JS) que funciona como Calculadora de Prévia de Holerite. Ele recebe dados da folha (salário, horas extras, descontos), calcula tributos automaticamente (INSS, IRRF, FGTS) e gera um contracheque clássico de duas vias, interativo, espelhado em tempo real e formatado diretamente para impressão.
